## 2. Metric definitions

| Metric | Definition | Unit |
|---|---|---|
| $f$ | leak / $(n_{key}\,h(Q))$ | — |
| FER | failed or unverified frames / total | — |
| Throughput | $n \cdot F_{max} / (I_{avg} \cdot C_{iter})$ | Mbps |
| Latency | worst case at $I_{max}$ | µs |
| Energy per bit | power / throughput | nJ/bit |
| Secret key rate | $\ell$ per second | bps |
