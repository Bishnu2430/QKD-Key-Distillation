## Observations worth keeping
- The critical path is **block-RAM clock-to-output with zero logic levels** — memory access, not arithmetic, set the speed here. Expect the same shape in the decoder, so pipeline around memories.
- **Block RAM is 75% of dynamic power** even in this tiny design. With 30–45 BRAMs in the decoder, memory traffic will dominate power, so reducing passes over the APP array is a power optimisation as well as an area one.
- Leakage is 93% of total power at this size; only the full accelerator will give a meaningful dynamic/static split.
